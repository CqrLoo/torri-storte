# Torri Storte

Gioco multiplayer di torri di blocchi con fisica Box2D (planck.js) e Socket.io.
Modalità Gara, Sopravvivenza e Rompicapo, torri da incastro, magie e coppe a round con punteggi.

## Avvio

    npm install
    npm start

Apri http://localhost:3000. In rete locale gli amici aprono http://IL-TUO-IP:3000.
